CANOPI Studio — recorded demo
=============================

Open index.html in any browser. Nothing else is needed: no install, no server,
no GPU, no network connection. Nothing is sent anywhere.

Every figure and number was produced by the real renderer on an NVIDIA A40.
The controls replay those recorded runs rather than computing new ones, so
changing a parameter and pressing Render shows the recorded result for that
stand and says so. Step 5 prints the script that recomputes it from the code.

Recorded 2026-08-24.
