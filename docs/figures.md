# Paper figure map

Every figure in the paper that is produced by code, and the script that produces it.
Run commands from the repository root; output goes to `$CANOPI_FIG_DIR` (default `./figures`).

## Scene description

| Published file | Script | Command |
|---|---|---|
| `jbs_tree_positions_18groups.pdf` | `paper/fig_tree_positions.py` | `python paper/fig_tree_positions.py` |

Reads the 18 downloaded `*_treelocations.dat` files and plots tree positions coloured by species.
CPU only, ~5 s.

| `convergence_fic_edg_P0.5_CV0.5_LADSPH_SZA60.eps` | `paper/fig_convergence_fic_edg.py` | `python paper/fig_convergence_fic_edg.py` |

|---|---|---|
| `multiang_angular.eps` | `lai_inversion_toy_angular.eps` | `paper/fig_multiang_toy.py` |

```bash
python paper/fig_multiang_toy.py
```

> **Note on naming.** The four `multiang_*.eps` files in the manuscript are the
> `lai_inversion_toy_*.eps` outputs of this script, renamed when they were copied into the
> article directory. They are byte-identical apart from the embedded PostScript timestamp.
> The script keeps its own output names; map them as in the table above.

Useful flags: `--fix-rho`, `--nir-only`, `--red-only`, `--nadir-only`,
`--lai-init`, `--rho-init`, `--lai-true`, `--k-max`, `--lm-lambda`, `--max-iter`.

## Spatially resolved BRF and per-species derivatives

| Published files | Script |
|---|---|
| `jbs_O17_nadir_brf.eps`, `jbs_O17_hotspot_brf.eps` | `paper/fig_jbs_species_images.py` |
| `jbs_O17_{nadir,hotspot}_dopt_{BEPE,TICO,ALGL,POTR,PIAB,FREX,ACPL}.eps` (14) | `paper/fig_jbs_species_images.py` |
| `jbs_O17_nadir_contrib_{BEPE,…,ACPL}.eps` (7) | `paper/fig_jbs_species_images.py` |

```bash
python paper/fig_jbs_species_images.py --band O17 --res 512 --n-spp 32
```

Renders 512×512 at nadir and at the hotspot, aggregates the 18 size-groups to 7 species, and
writes each panel standalone (no titles — captions live in the LaTeX) plus combined 2×4 overview
figures. Roughly an hour on an A40 for the published settings; drop to `--res 128 --n-spp 8`
for a quick look.

## Joint LAI + reflectance retrieval

Two runs of one script, then a shared replot pass.

```bash
# 1 — joint LAI + rho, 21 parameters
python paper/fig_inversion_species.py --init-p-lai 0.35 --k-max 0 \
       --out-prefix lai_rho_species_p035_k0

# 2 — LAI only, reflectance held at truth
python paper/fig_inversion_species.py --init-p-lai 0.35 --k-max 0 --true-rho \
       --out-prefix lai_species_truerho_p035_k0

# 3 — all 27 publication EPS from the two result files
python paper/fig_inversion_replot.py
```

Step 1 produces `lai_rho_species_p035_k0_*`:
`cost`, `rmse`, `lai_conv`, `lai_error`, `rho_O08_conv`, `rho_O08_error`, `rho_O17_conv`,
`rho_O17_error`, and `{O08,O17}_{obs,init,final,resid}`.

Step 2 produces `lai_species_truerho_p035_k0_*`:
`rmse`, `lai_conv`, `lai_error`, and `{O08,O17}_{obs,init,final,resid}`.

Each run also writes `<out-prefix>_p0.35_k0.pkl` holding the complete iteration history; pass
`--plot-only` to replot from it. Step 3 reads both `.pkl` files, so run steps 1 and 2 first.

**Step 3 needs LaTeX** — it sets `text.usetex=True` for publication typography. The simulations
themselves have no LaTeX dependency.
